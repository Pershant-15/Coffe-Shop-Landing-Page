this # ☕ Vistra Coffee

A modern and responsive coffee shop landing page built with **HTML** and **Tailwind CSS**.

Vistra Coffee is designed to provide a clean, elegant, and user-friendly online experience for a modern coffee shop.

## ✨ Features

- ☕ Modern coffee shop landing page
- 📱 Fully responsive design
- 🧭 Responsive navigation bar
- 🖼️ Attractive hero section
- ☕ Coffee/product showcase
- 📖 About section
- 📍 Location/contact section
- 🔘 Call-to-action buttons
- 🎨 Modern UI built with Tailwind CSS
- ⚡ Fast and lightweight frontend
